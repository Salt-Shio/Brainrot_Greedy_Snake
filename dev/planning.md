# 新增功能說明

## 控制方式 

- Morse Code

## 地圖

- 大小: 有限但不會撞死，會鏡像循環 ( Mirror/Flip Wrap)

## 主動觸發

- 定期主動觸發 67 Boss 
    - Boss 的 67 聲效會越來越大聲，最大聲的時候 67 battle
    - 需要跟 Boss 67 battle 獲勝
    - 技術
        - 用 Mediapipe 判斷玩家 67
        - 聲效控制

- 炸彈鱷魚 Boss 定期轟炸
    - 炸彈鱷魚的腦腐聲也會越來越大
    - 玩家要躲過一段時間後會落下的炸彈
    - 技術
        - 顏色變化，要轟炸的地方越來越紅
